# E-Commerce Sales Dashboard

## Overview
An interactive Power BI dashboard that analyzes e-commerce sales performance and provides valuable business insights.

## Features
- Sales by State
- Profit by Month
- Category-wise Sales
- Payment Mode Analysis
- Customer-wise Sales
- Sub-category Profit Analysis

## Tools Used
- Power BI
- Power Query
- DAX
